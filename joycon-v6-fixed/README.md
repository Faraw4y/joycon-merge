# Joy-Con Merge

Menggabungkan Left + Right Joy-Con menjadi satu virtual gamepad di Android.

> **Root required** — KernelSU atau Magisk

---

## Download

Unduh APK terbaru dari halaman [Releases](../../releases/latest).

---

## Cara pakai

1. Sambungkan **kedua Joy-Con** via Bluetooth
2. Buka app → tap **START**
3. KernelSU/Magisk akan meminta izin root → **Grant**
4. Virtual gamepad aktif — siap dipakai di game

---

## Fitur

- Auto-detect Left & Right Joy-Con
- Auto-start saat boot
- Button remapping (tab Remap)
- Stick calibration — deadzone, fuzz, axis inversion (tab Calibrate)
- Gamepad tester visual (tab Test)
- Screenshot button (Capture) didukung

---

## Requirements

- Android 8.0+
- KernelSU atau Magisk (root)
- Kedua Joy-Con sudah ter-pair via Bluetooth sebelum START
